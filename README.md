# Medical Insurance Cost Analysis

## Project Overview

This project analyzes medical insurance data to understand the factors associated with variations in insurance charges. Python was used for data cleaning, Exploratory Data Analysis (EDA), statistical analysis, and data visualization.

## Objectives

* Analyze medical insurance charges.
* Understand the impact of smoking status on insurance costs.
* Explore the relationship between age, BMI, and insurance charges.
* Compare average insurance charges across gender and regions.
* Analyze insurance costs based on the number of children.
* Identify patterns and trends in medical insurance expenses.

## Dataset

* **Dataset:** Medical Cost Personal Dataset
* **Original Records:** 1,338
* **Features:** 7 columns
* **Target Variable:** Charges

## Tools & Technologies

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## Project Workflow

1. Loaded and inspected the dataset.
2. Checked missing values and duplicate records.
3. Cleaned the data by removing duplicate records.
4. Performed Exploratory Data Analysis (EDA).
5. Analyzed insurance charges across different customer groups.
6. Studied relationships between numerical variables.
7. Created visualizations to communicate key findings.

## Key Insights

* Average medical insurance charges were approximately $13,279.
* Smokers had substantially higher average insurance charges than non-smokers.
* Age and BMI showed positive relationships with insurance charges.
* The Southeast region had the highest average insurance charges among the four regions.
* Customers in the obese BMI category had higher average insurance charges than those in the other BMI categories.

## Conclusion

This project identified patterns in medical insurance charges and explored how smoking status, age, BMI, gender, number of children, and region were associated with insurance costs. The findings demonstrate how data analysis can support a better understanding of medical insurance expenses.
